Aventuria Helpers

Add-on module for Aventuria, adding extra macros and a completely redesigned hero sheet, built on the Universal Tabletop System.

All code and documentation in this module were created with AI assistance. The screenshots below are not AI-generated - they come from the Aventuria module.

Features

  • New hero sheet: directly rollable checks, a cleaner layout, weapon exhaustion, and special abilities - an early draft, the design is still work in progress.
  • Hero tray: deck, discard pile, hand, and played cards at a glance, including endurance management and card preview.
  • Setup guide: walks step by step through world setup, hero assignment, quickstart preparation, and running the adventures.
  • Extended combat tracker: initiative handled according to the Aventuria rules, with a fixed enemy-actions slot and an end-of-round prompt.

More info, full feature list, and issue tracker: GitHub

Deutsch

Zusatzmodul für Aventuria mit zusätzlichen Macros und einem komplett neu gestalteten Heldenbogen, aufbauend auf dem Universal Tabletop System.

Der gesamte Code und die Dokumentation dieses Moduls sind mit KI-Unterstützung entstanden. Die Screenshots oben stammen dagegen nicht von KI, sondern aus dem Aventuria-Modul.

Funktionen

  • Neuer Heldenbogen: Direkt würfelbare Proben, übersichtliches Design, Erschöpfen von Waffen und Sonderfertigkeit - erster Entwurf, das Design ist noch Work in Progress.
  • Heldenablage: Deck, Ablage, Hand und Ausgespielte Karten auf einen Blick, inkl. Ausdauer-Verwaltung und Kartenvorschau.
  • Einrichtungs-Guide: führt Schritt für Schritt durch Welt-Einrichtung, Heldenzuweisung, Schnellstarter-Vorbereitung und das Leiten der Abenteuer.
  • Erweiterter Kampf-Tracker: Die Initiative wird nach den Aventuria-Regeln gehandhabt, mit festem Gegneraktionen-Platz und Rundenende-Abfrage.
